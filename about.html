About this page

How it was made, and how to make your own.

One person, a week of notes, and an AI coding assistant. No designers, no engineers, no budget. If you have a repetitive job and a spreadsheet, you can do this too.

How is this made?

Plain files on a free host.

A handful of files

Two HTML pages, one stylesheet and two small scripts. No build step and no framework. Open them in any browser.

Free hosting

The files live on GitHub. GitHub Pages publishes them. Every time a change is saved to the main branch, the site updates in about a minute.

Built with Claude

Claude Code read the notes, pulled the numbers, wrote the pages and checked them in a browser. A person set the goals, made the calls, and reviewed every word.

The 3D home
Drawn in code with three.js, a free 3D library. Simple boxes and cones, no 3D files. If your browser cannot show 3D, the buttons and captions still tell the story.
The charts
Drawn by hand in SVG. Each one has a text summary and a table view, so it works with a screen reader.
The brand
Colors and type match avantstay.com and our Guest Experience journey site: navy, teal, Source Sans 3, and Fraunces for headings.
Accessibility
Skip link, real headings, keyboard play for the game and sliders, visible focus, contrast checked for WCAG AA, and motion turned off if you ask your device for less motion.

If I'm inspired, how can I do this?

Seven steps to automate your own busywork.

This works for any team that gets alerts, checks a few systems, and logs what they did. Swap "noise alert" for your own trigger.

  1. Watch someone do the job

    Sit in on a real shift. Record it. Write down every tool they open and every time they copy something from one place to another. That copying is your target.

  2. Count it

    Pull the log they already keep. How many items a day? How many needed action? If most need nothing, a bot can do the sorting.

  3. Write the rules down

    Find the SOP, or write one. Turn it into "if this, then that" sentences. Have the team lead check them. A bot is only as good as its rules.

  4. Build the lookup sheet

    Make one Google Sheet that holds what the agent hunts for: one row per home, with risk, camera login name and neighbors. Have the team fill the gaps.

  5. Get the alerts into one place

    Find what already sends alerts. Here, that was Alex in Slack. Ask the owner to send all of them to one channel. This often needs no code.

  6. Wire it up in Make.com

    Make.com (or Zapier) connects apps with drag-and-drop blocks. A first version of this bot is six blocks:

    1. Slack       Watch new messages in #noise-alerts
2. Text parser Pull out home name, noise level, minutes
3. Sheets      Search the property map for that home
4. Router      Apply the rules: empty home? low risk? very high?
5. Slack       Reply in a thread with the facts and outcome buttons
6. Sheets      Add a row to the monthly report

    A second scenario listens for the button tap and updates the row with the outcome.

  7. Run it in shadow mode first

    Let the bot post what it would do, next to what people actually do, for two weeks. Only let it act alone once it agrees at least 9 times out of 10.
